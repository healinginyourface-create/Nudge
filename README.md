# Nudge

심심할 때 무엇을 할지 추천해주는 스와이프 기반 활동 추천 웹앱입니다.

## Features

- 활동 데이터 기반 추천
- 랜덤 활동 추천 API
- 조건별 활동 필터링
- 좋아요 / 싫어요
- 좌우 스와이프 방식의 활동 선택
- FastAPI + JavaScript 기반 웹앱
